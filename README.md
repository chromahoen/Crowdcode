# Crowdcode

A crowdcoding app: many hands on one codebase.

This repository is **public to read** and **invite-only to build**. Anyone may read it, fork it and
learn from it. Only people Troy invites as collaborators can write to it — there is no "join" button,
no self-service access, and nothing here is open to anonymous contribution.

## Contribution model

- **Read:** public. Clone, read, fork, cite.
- **Write:** by invitation only. Collaborators are added one at a time, by name.
- **The default branch is guarded.** Nobody pushes to it directly, not even collaborators: every
  change arrives as a pull request, approvals are required, and force-pushes and deletions are
  rejected by a ruleset on the default branch.
- **Pull requests from forks** may still be opened by anyone, because the repository is public. They
  are not a route to write access; nothing merges without review.
